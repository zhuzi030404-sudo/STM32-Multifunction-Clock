# 操作说明

按键1=PB1，按键2=PA6，按键3=PA4；长按指按住3号键至少约1秒后松开。普通页面以松手识别操作，游戏用按下事件立即响应。

| 页面 | 操作 |
| --- | --- |
| 主页 | 键1/2切换数字与指针，短按3进入菜单，长按3息屏 |
| 息屏 | 任意按键松手唤醒回主页；该次事件只唤醒，不同时进入菜单 |
| 菜单 | 键1/2前后移动，旋钮切换选项，短按3确认，长按3回主页 |
| 时间设置 | 键1增加、键2减少，短按3下一项，最后一项确认保存，长按3取消 |
| 秒表 | 键1开始，键2停止，短按3停止并清零，长按3回菜单 |
| 灯光 | 键1开灯，键2关灯，键3回菜单；退出页面保留灯状态 |
| 倒计时 | 未运行时键1加10秒、键2减10秒；短按3开始/暂停/完成后重来，长按3回菜单 |
| 蜂鸣提醒 | 倒计时到零后响200毫秒、停800毫秒，最长10秒；按键可消音 |
| 亮度 | 键1自动/手动；键2在手动时切档，在自动有效采样时反向，无效采样时重试；键3返回 |
| 运动数据 | 键1重新连接，键3回菜单 |
| 姿态 | 键1重新初始化和静止校准，键3回菜单 |
| 水平仪 | 有效状态键1设参考零点，失败状态键1重试，键3回菜单 |
| 小恐龙 | 键1按下跳跃，失败后再按1重开；长按3松手回菜单 |
| 表情 | 键1/2切换六种表情，键3回菜单 |

旋钮目前只控制菜单移动，没有独立按压确认，也不直接编辑时间或亮度。旋转方向及一个机械卡点对应多少电气步数需要结合具体模块确认。

倒计时与秒表状态在主循环维护，离开相应页面不会停止；运动校准仍包含阻塞等待，整个系统不应被描述为所有任务完全无阻塞。息屏不是整机休眠。
